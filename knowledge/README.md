# knowledge/

Craft lessons and checklists. Each lesson states what a professional rejected as a draft, why, and
the concrete fix, so an agent can avoid the mistake without having made it.

Lessons describe craft (timing, legibility, motion quality, sound sync, render pitfalls), never a
house style. Anything that is a matter of taste is written as an option the user can choose.

| File | Use it |
| --- | --- |
| [lessons.md](lessons.md) | Before planning a film: what was rejected as a sketch, why, and the fix; rhythm, motion, type, sound and 3-D rules |
| [checklist.md](checklist.md) | Before showing anything: picture, motion, objects, sound and delivery checks |
| [critique.md](critique.md) | Every round of the quality loop: what to look at, how to score, the output format |
